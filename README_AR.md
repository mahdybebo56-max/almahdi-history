# المهدي في التاريخ - النموذج الأولي

هذا مشروع Flutter مبدئي لتطبيق تعليمي يعمل على Android و iOS.

## ما الموجود حاليًا؟
- واجهة عربية بتصميم أسود وذهبي.
- اختيار وضع المدرس أو الطالب (للتجربة فقط).
- لوحة رئيسية مختلفة لكل دور.
- إنشاء مجموعات للمدرس مع كود انضمام.
- إدخال كود المجموعة من حساب الطالب والانضمام محليًا.
- صفحات أولية للامتحانات والمذكرات والمساعد الذكي.

## التشغيل
1. ثبّت Flutter SDK وثبّت Android Studio أو VS Code.
2. فك ضغط المشروع.
3. افتح مجلد `almahdi_history` في المحرر.
4. من الطرفية داخل المجلد نفّذ:

```bash
flutter pub get
flutter run
```

## ملاحظات مهمة
هذه نسخة واجهات وتجربة محلية فقط. البيانات لا تُحفظ على خادم ولا تنتقل بين جهاز المدرس والطالب.
تغيير الدور لا يمثل تسجيل دخول آمنًا. قبل الاستخدام الحقيقي نحتاج إضافة:
- تسجيل حسابات آمن وصلاحيات مدرس/طالب.
- قاعدة بيانات سحابية ومزامنة بين الأجهزة.
- طلبات انضمام وموافقة المدرس.
- حفظ الحضور والدرجات والاشتراكات.
- رفع المحاضرات والملفات.
- ربط خدمة ذكاء اصطناعي بمفتاح API محفوظ على خادم آمن، وليس داخل التطبيق.
- اختبارات حماية وخصوصية، ثم تجهيز النشر على Google Play و App Store.

## بنية المشروع
- `lib/main.dart`: واجهات التطبيق والمنطق التجريبي.
- `pubspec.yaml`: إعدادات Flutter.

## بناء APK على Windows
بعد تثبيت Flutter SDK و Android Studio وإعداد Android SDK:
1. فك ضغط المشروع.
2. افتح مجلد المشروع.
3. اضغط مرتين على `build_android.bat`.
4. عند نجاح البناء ستجد الملف في:
   `build/app/outputs/flutter-apk/app-release.apk`

هذا الأمر ينشئ APK تجريبيًا غير موقّع بمفتاح نشر خاص. قبل النشر على Google Play يلزم إعداد توقيع إصدار خاص بك.
